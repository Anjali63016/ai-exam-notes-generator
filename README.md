# AI Exam Notes Generator 📚

An AI-powered web app that generates:
- smart summaries
- keywords
- quiz questions
- quick revision points

from uploaded PDF notes.

## Features
✅ PDF Upload  
✅ Text Extraction  
✅ AI Summary  
✅ Important Keywords  
✅ Quiz Questions  
✅ Revision Notes  

## Technologies Used
- Python
- Streamlit
- NLTK
- Sumy
- PDFPlumber

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
